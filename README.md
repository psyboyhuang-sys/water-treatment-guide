# 從水庫到水龍頭：現代淨水場實景工程導覽 (Water Treatment Plant Interactive Exhibit)

結合現場實景紀實攝影、微觀物理化學機制與第一線工程師操作規格的互動式圖鑑網站。

## ✨ 核心功能
- **📜 滾動式敘事長卷 (Scrollytelling)**：隨滑鼠滾動自動切換 8 大淨水程序實景照片與水質變化儀表板（濁度、自由有效餘氯、Zeta 電位、水力停留時間）。
- **➕ 現場工程設備熱點標註 (Interactive Hotspots)**：標示分層取水閘門、快混渦輪機、V 型鋸齒溢流堰、雙層濾床等關鍵構造。
- **↔️ 50/50 雙圖拖曳對比滑桿**：直接左右拖曳比較「日常滿水運轉實景」與「歲修排空構造／水質特寫」。
- **🗂️ 全覽卡片牆與深度規格燈箱**：一鍵切換卡片牆，點開燈箱可檢視「白話原理解說」、「工程設計參數與法規」、「現場工程師實務筆記」。
- **⚡ 高級淨水與用戶端管網專區**：完整收錄臭氧 (Ozonation)、生物活性碳 (BAC)、薄膜處理 (UF/RO) 及出廠後至頂樓水塔的風險解析。
